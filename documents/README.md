# BA Case Study Documents — Face Recognition with KD-Tree

These are draft portfolio artifacts created by Parichart Saeyhoong as a learning exercise based on an academic prototype.

**Important:** These documents were not collected from or approved by a real client. Some requirements are proposed assumptions and are labelled accordingly. Test cases are designed only; no Pass/Fail result is claimed until the cases are executed against the system.

## Files
- `BRD.md` — business context, objectives, scope, and assumptions
- `FRS.md` — functional requirements and acceptance criteria
- `Use-Case.md` — actor, preconditions, main flow, and exceptions
- `Test-Cases.md` — test scenarios, steps, expected results, and execution status
- `RTM.md` — mapping between BRs, FRs, and designed test cases
